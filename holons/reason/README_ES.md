## El caos que resuelve

**Inferencia**: conclusiones que exceden lo que el dato sostiene.

Este holon existe porque ese caos se diagnostica en organizaciones reales. Si un
diagnóstico no lo encuentra, no se construye.

## Teoría

El razonamiento neuro-simbolico es un salto de nivel. Cardinal y Meta cubren hoy la mayor parte del valor real para el cliente.

## Qué produce

Inferencia neuro-simbolica y anclaje simbólico.

## Señal de validación

Esto es un criterio mecánico, no una pregunta. No hay cliente al que preguntarle hasta que se cumpla la precondición.

> Se reactiva cuando Meta necesite anclaje simbólico y el cuello de botella ya no sea confianza sino inferencia.

### Condición de reactivación

Se reactiva cuando Meta necesite anclaje simbólico y el cuello de botella ya no sea confianza sino inferencia.

**Por qué se aplaza:** construirlo antes no aporta al problema que el cliente tiene hoy.

## Dependencias

Ninguna. Aplazado.

## Superficies

| Superficie | Para quién | Forma |
|---|---|---|
| Desarrollador | Quien construye | API, SDK, servidor MCP, CLI |
| Agente | Sistema de IA | Herramientas MCP invocables |
| Humana | Persona no técnica | Interfaz, carga, corrección |
| Empresa | Tiene que responder ante alguien | Panel de gobierno, auditoría, SLA, aislamiento |

Regla dura: si una capacidad solo existe dentro de una interfaz humana, es
consultoría disfrazada de software. Todo lo que se le hace al cliente tiene que existir
como API.
